ANYtoANY - Linux versiyasi
==========================

Ishga tushirish:
  ./anytoany

Kerakli dasturlar (Ubuntu / Debian / Linux Mint):
  sudo apt install ffmpeg libjson-glib-1.0-0 xdg-utils

Fedora:
  sudo dnf install ffmpeg json-glib xdg-utils

Izoh: .deb paketidan o'rnatsangiz, bular avtomatik o'rnatiladi.
Video va audio fayllar kompyuterdagi pleyerda ochiladi (VLC, Videos va h.k.).
Tayyor fayllar "Yuklanmalar" (Downloads) papkasiga saqlanadi.
