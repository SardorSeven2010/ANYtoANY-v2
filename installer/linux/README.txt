CORE - Linux versiyasi
======================

Ishga tushirish:
  ./core

Kerakli dasturlar (Ubuntu / Debian / Linux Mint):
  sudo apt install ffmpeg libmpv2 libjson-glib-1.0-0 xdg-utils

Fedora:
  sudo dnf install ffmpeg mpv-libs json-glib xdg-utils

Izoh: .deb paketidan o'rnatsangiz, bular avtomatik o'rnatiladi.
Video va audio fayllar ilovaning o'z pleyerida ochiladi (libmpv orqali).
Tayyor fayllar "Yuklanmalar" (Downloads) papkasiga saqlanadi.
